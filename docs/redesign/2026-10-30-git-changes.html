What it costs to build. Backend: record HEAD at spawn; on refresh run git log --numstat start..HEAD and git diff --numstat (+ untracked) — when the session goes idle (Stop hook), on window focus and when the panel opens; one in flight per folder. Diff pane: git diff / git show for one file, rendered read-only (a unified diff is lines with a prefix — no new dependency). Frontend: a Changes tab in the right dock, +/− on tab and row, the diff as a new pane content kind. Read-only throughout.
